# Dashboard (Phase 3)

Power BI report "Knowledge Integrity Monitor" on top of the Gold star schema.

- `POWERBI-GUIDE.md`: how to open, refresh and save the report, and how to build it by hand
- `powerbi/databricks/Knowledge Integrity Monitor.pbip`: Power BI project connected to Databricks (Import mode)
- `powerbi/csv/Knowledge Integrity Monitor CSV.pbip`: same project, reads the CSV extracts in `sample_gold/`
- `CONNECTION.md`: SQL warehouse connection details (no token)
- `theme.json`: report theme
